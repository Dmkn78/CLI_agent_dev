# Parcours ciblés et oracle visible

Choisir les lignes pertinentes ; ce tableau ne lance aucune campagne.

| Zone | Parcours | Résultat à observer |
|---|---|---|
| Navigation | survol/focus maison, dossier, agents ; replier/réouvrir | infobulle lisible et nom accessible ; libellés visibles en barre étendue |
| Chat | plusieurs onglets, renommage, fermeture, zoom/restauration | titre explicite conservé ; sélection correcte ; zoom réel du contenu |
| Terminal | image synthétique, choix permissions, resize, fermeture | chemin/arguments transmis ; permissions effectives ; arrêt du bon processus |
| Canaux | 1, 3 puis 8 participants, choix indépendants fictifs | noms/modèles/efforts conservés ; aucun plafond implicite à deux |
| Discussion | envoyer, lancer, observer, arrêter | reçu distinct de lancement ; activité par participant ; arrêt effectif |
| Consommation | absente, zéro mesuré, tours multiples, reprise | absence distincte de zéro ; cumul sans double compte |
| Diagnostic | erreur fournisseur fictif ou approbation en attente | erreur/action requise visible et liée au participant |

Vraie réponse modèle, authentification ChatGPT et dépôt externe dépendent des autorisations propres à ces actions. Une fixture prouve le flux local, pas l’accès à un modèle réel.
