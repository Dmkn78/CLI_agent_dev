# Grille d’observation ciblée

| Contrôle | Observation utile | Régression |
|---|---|---|
| Icône navigation | nom en barre ouverte, nom accessible, infobulle survol/focus | maison/dossier/agents après repli |
| Sélecteur | label, valeur lisible, options, sélection | nom long et effort différent du voisin |
| Modal | focus initial, Tab, fermeture, retour | liste déployée, fenêtre étroite, zoom |
| Canaux | tous participants atteignables, action/retour explicites | 3/8 participants, activité/erreur/arrêt |
| Onglets | nom, fermeture, sélection perceptibles | deux chats, nom long, renommage |
| Tokens | mesure ou absence, cumul compréhensible | zéro reçu, mesure absente, plusieurs tours |

Sources primaires inspectées le 3 octobre 2026 :

- [Deque — axe-core](https://github.com/dequelabs/axe-core), Accessibility Rules/Getting started : moteur HTML et résultats demandant revue manuelle. Application : compléter clavier et observation, ne pas transformer un résultat automatique en certification.
- [Microsoft Playwright — Best practices](https://github.com/microsoft/playwright/blob/main/docs/src/best-practices-js.md), comportement visible et isolation : contrôles rendus, état de recette propre.
