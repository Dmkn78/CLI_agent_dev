# Contrat pédagogique

Le lecteur suit : situer → définir → prédire → manipuler → relier aux symboles
→ reconstruire → transférer. Les réponses sont enregistrées, jamais assimilées
automatiquement à une maîtrise. Une correction QCM n'est qu'une preuve locale.

Chaque chapitre contient : concept et prérequis ; intuition ; formule et
variables ; expérience avec paramètres et conséquences ; piège avec un réglage
concret ; preuve progressive ; exercice de reconstruction ; un transfert utile ;
références vers les pages sources ; limites et questions après manipulation.

Contrats des expériences intégrées :

| Expérience | Variables / plage | Intuition / piège | Cas connus |
|---|---|---|---|
| Brownien avec dérive | μ −1..1, σ 0..2, horizon 0.5..5, 4..64 trajectoires | La dispersion croît comme √t ; doubler σ multiplie la variance par 4. Une trajectoire n'est pas une espérance. | σ=0 : μt ; μ=0 : moyenne d'ensemble proche de 0 |
| Espérance discrète | poids non négatifs de trois issues −2,1,5 | Le centre de masse peut être une valeur jamais réalisée. Les poids sont normalisés. | poids central seul : 1 ; poids uniformes : 4/3 |
| Dérivée | x −2..2, h 0.01..2 ; f(x)=x² | La sécante tend vers la tangente ; h n'est pas nul dans le quotient. | pente=2x+h ; erreur=h |
| Densité gaussienne 2D | corrélation −0.9..0.9, vue orbitale | La corrélation tourne et resserre les ellipses ; hauteur n'est pas probabilité ponctuelle. | ρ=0 : symétrie radiale ; densité à l'origine=1/(2π√(1−ρ²)) |

Questions après manipulation : qu'est-ce qui a changé ? Qu'est-ce qui est resté
invariant ? Quel symbole de la formule l'explique ? Quel réglage contredit ton
intuition initiale ? Dans quelle situation l'utiliserais-tu ?

Ces expériences sont reproductibles avec une graine et testées sur des cas
analytiques. Les visualisations spécifiques générées sont marquées à relire,
isolées dans une iframe et ne sont pas exécutées sur le système hôte.
